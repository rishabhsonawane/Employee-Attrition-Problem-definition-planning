Employee Attrition Analysis

Project Overview

This project focuses on analyzing employee attrition using HR employee data. Employee attrition means employees leaving the company. The purpose of this project is to understand the employee data and identify patterns that may be related to employees leaving the organization.

Employee attrition can affect a company by increasing recruitment and training costs and causing the loss of experienced employees. Through this project, I performed exploratory data analysis to better understand different employee-related factors.

Project Objectives

Understand the employee attrition problem.
Explore the HR employee dataset.
Identify the target variable and different feature types.
Check the data for missing values and duplicate records.
Analyze the distribution of employee features.
Analyze employee attrition.
Compare attrition with overtime, job role, department, and business travel.
Perform correlation analysis.

Dataset Information

The dataset used for this project contains information about employees and their work-related details.

  Number of rows: 1470
  Number of columns: 35
  Target variable: Attrition
  Missing values: None

The dataset includes features such as age, department, job role, monthly income, overtime, job satisfaction, work-life balance, and work experience.
